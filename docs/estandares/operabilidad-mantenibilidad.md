# EQ-15 — Operabilidad y mantenibilidad

## 1. Nombre del estándar
**ID:** EQ-15  
**Nombre:** Operabilidad y mantenibilidad

## 2. Propósito
Garantizar que el sistema pueda operarse y mantenerse con bajo fricción.

## 3. Alcance
Aplica a sistemas desplegados o desplegables.

## 4. Definición del estándar
El sistema debe ser operable por terceros.

## 5. Criterios de aceptación
- [ ] Despliegue claro
- [ ] Monitoreo posible
- [ ] Mantenimiento viable

## 6. Evidencias esperadas
- scripts
- documentación
- monitoreo

## 7. Antipatrones comunes
- Operación manual compleja
- Dependencia de individuos

## 8. Nivel de criticidad
**Alto**

## 9. Relación con otras prácticas y estándares
Prácticas: 12  
Estándares: EQ-09

## 10. Observaciones
Un sistema inoperable no es un sistema terminado.
