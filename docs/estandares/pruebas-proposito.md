# EQ-07 — Pruebas con propósito

## 1. Nombre del estándar
**ID:** EQ-07  
**Nombre:** Pruebas con propósito

## 2. Propósito
Asegurar que las pruebas aporten confianza real y protejan contra regresiones.

## 3. Alcance
Aplica a lógica crítica, flujos clave y componentes de alto impacto.

## 4. Definición del estándar
Las pruebas deben existir para reducir riesgo, no para inflar métricas.

## 5. Criterios de aceptación
- [ ] Las pruebas cubren lógica crítica
- [ ] Las pruebas son mantenibles
- [ ] Existe alineación con criterios de aceptación
- [ ] Las pruebas detectan regresiones reales

## 6. Evidencias esperadas
- suites de pruebas
- reportes de ejecución
- pipelines de CI

## 7. Antipatrones comunes
- Cobertura sin sentido
- Tests frágiles
- Tests duplicados

## 8. Nivel de criticidad
**Alto**

## 9. Relación con otras prácticas y estándares
Prácticas: 5, 8  
Estándares: EQ-02, EQ-06

## 10. Observaciones
Probar todo no es el objetivo. Probar lo importante sí.
