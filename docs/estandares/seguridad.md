# EQ-10 — Seguridad mínima obligatoria

## 1. Nombre del estándar
**ID:** EQ-10  
**Nombre:** Seguridad mínima obligatoria

## 2. Propósito
Reducir exposición innecesaria y riesgos evitables.

## 3. Alcance
Aplica a todo sistema con acceso a datos o recursos.

## 4. Definición del estándar
Se debe aplicar seguridad básica por diseño.

## 5. Criterios de aceptación
- [ ] Mínimo privilegio
- [ ] Datos sensibles protegidos
- [ ] Accesos controlados

## 6. Evidencias esperadas
- configuraciones
- políticas
- revisiones de seguridad

## 7. Antipatrones comunes
- Credenciales expuestas
- Permisos excesivos

## 8. Nivel de criticidad
**Crítico**

## 9. Relación con otras prácticas y estándares
Prácticas: 7  
Estándares: EQ-03

## 10. Observaciones
La seguridad básica no es negociable.
