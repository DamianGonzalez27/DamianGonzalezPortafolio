# EQ-14 — Documentación mínima suficiente

## 1. Nombre del estándar
**ID:** EQ-14  
**Nombre:** Documentación mínima suficiente

## 2. Propósito
Asegurar comprensión y continuidad.

## 3. Alcance
Aplica a sistemas, flujos y decisiones relevantes.

## 4. Definición del estándar
Debe existir documentación proporcional a la complejidad.

## 5. Criterios de aceptación
- [ ] Instrucciones claras
- [ ] Contexto técnico
- [ ] Decisiones documentadas

## 6. Evidencias esperadas
- documentación técnica
- README
- diagramas

## 7. Antipatrones comunes
- Documentación inexistente
- Documentación obsoleta

## 8. Nivel de criticidad
**Medio**

## 9. Relación con otras prácticas y estándares
Prácticas: 3, 15  
Estándares: EQ-01
